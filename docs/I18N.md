# Internationalization (i18n) Guide — W Automobiles

> **Translation Review Status**:
> - `messages/fr.json`: **Source of truth** (production French wording).
> - `messages/en.json`: **draft, needs native review**
> - `messages/ar.json`: **draft, needs native review**

## Architecture

- **Library**: `next-intl` v4 with Next.js 14 App Router (`middleware.ts`).
- **Locales**: `fr` (default, unprefixed via `localePrefix: "as-needed"`), `en` (`/en/...`), `ar` (`/ar/...`, `dir="rtl"`).
- **Routing**: Defined in [`i18n/routing.ts`](../i18n/routing.ts) with `localeDetection: false` so shared URLs and crawlers never get redirected by `Accept-Language` or IP. Returning visitors who explicitly switch language store `NEXT_LOCALE` (`Max-Age=31536000; SameSite=Lax`), which redirects only on the bare domain `/`.
- **Navigation**: Public components use `Link`, `usePathname`, `useRouter`, and `redirect` from [`i18n/navigation.ts`](../i18n/navigation.ts). `/admin/*` stays outside `[locale]`.
- **Fonts**: French/English load `Cormorant Garamond` + `Inter`; Arabic loads `Amiri` + `Cairo` (`preload: false` so FR/EN visitors never download Arabic fonts). The `W AUTOMOBILES` wordmark stays Latin `dir="ltr"` with `0.22em` tracking in all locales.

## Namespaces

`messages/{fr,en,ar}.json` share identical keys across 14 namespaces:
`common`, `nav`, `home`, `catalogue`, `car`, `showroom`, `contact`, `location`, `footer`, `seo`, `whatsapp`, `errors`, `enums`, `admin`.

## Formatting & Enums

- Database enum values remain canonical French (`Essence`, `Diesel`, `Automatique`, `Neuf`, `Occasion`, `Disponible`, etc.) and map to `enums.*` via [`lib/labels.ts`](../lib/labels.ts).
- URL filter params use language-neutral keys (`fuel=essence`, `transmission=automatique`, `body=suv`, `condition=neuf`) while remaining backwards-compatible with legacy French query params (`carburant`, `boite`, `carrosserie`, `etat`, `marque`).
- Numbers, prices, mileage, power units (`ch` / `hp` / `حصان`), and dates (`Africa/Algiers`, Gregorian calendar, Latin digits `ar-DZ-u-nu-latn`) live in [`lib/format.ts`](../lib/format.ts).

## Tooling & Validation

Run before committing translation changes:

```bash
npm run i18n:check
```

This verifies:
1. Every key in `fr.json` exists and is non-empty in `en.json` and `ar.json` (and flags extra/orphan keys).
2. All ICU placeholders (`{brand}`, `{count}`, etc.) match across all three locales.
3. Basic scan for leftover hardcoded user-visible strings in `app/[locale]` and public `components/`.

In production, missing keys fall back to `messages/fr.json`. In development, missing keys render `[MISSING: namespace.key]` and log a console warning.
